# 实验参数优化建议复核清单

用途：对一份参数优化建议做结构化复核，确认推荐值、代理模型、预算与搜索策略彼此自洽。逐项勾选，未勾选项写明原因。

案例编号：__________　复核人：__________　复核日期：__________

## 1. 参数域

- [ ] 每个参数都有 `min`/`max`/`step` 或显式取值列表。
- [ ] 展开后的候选集与参数域一致，越界值未被纳入。
- [ ] 参数域来源（设备量程、材料限制、安全阈值）逐条可追溯。
- [ ] 候选数超过上限时的抽样方式已记录。

## 2. 约束

- [ ] 每条约束标注了作用参数、算符与阈值。
- [ ] 已应用与未应用约束分开列出，未应用项写明了缺失字段。
- [ ] 无可行解时没有被强行给出推荐值。

## 3. 观测数据

- [ ] 观测行的参数列与参数域名一一对应，单位一致。
- [ ] 观测数与可用拟合行数分别记录。
- [ ] 明显离群点被识别并说明是否影响拟合。
- [ ] 未把重复行的平均值与原始行混用。

## 4. 代理模型

- [ ] 模型类型、样本数、系数与残差标准差已给出。
- [ ] `R²` 或等价拟合指标与残差一起判读，未只看单一指标。
- [ ] 明确声明这是代理模型，不是机理模型。
- [ ] 推荐点落在观测覆盖区内；若在外，已标注为待验证假设。

## 5. 推荐值与可行区间

- [ ] 推荐值落在参数域与约束的交集内。
- [ ] 给出可行区间，而非只给一个点。
- [ ] 给出与次优点的预测差值，说明优势幅度。
- [ ] 预测响应未被表述为“已实测最优”。

## 6. 预算与排期

- [ ] `planned_runs` 与 `search_strategy` 的轮次表一致。
- [ ] `planned_cost = planned_runs × cost_per_run` 可复算。
- [ ] 同时满足预算上限与 `max_runs`；只满足一条时已标注。
- [ ] 预算不足时的降级路径已写明。

## 7. 停止与确认

- [ ] 停止判据包含预算耗尽、改进小于阈值、连续无改进、异常中止。
- [ ] 达到停止条件后会补一次确认运行，而不是直接定稿。
- [ ] 需要人工确认的约束放宽项已升级给实验负责人。

## 8. 风险与降级

- [ ] 覆盖无可行解、约束冲突、模型外推、重复不一致、预算不足。
- [ ] 每条风险有触发条件与处置动作。
- [ ] 数据缺失或指标矛盾时的降级输出已说明。
